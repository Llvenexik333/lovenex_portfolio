Nfnixbot VPN Specification

> ИДЕОЛОГИЯ ПРОЕКТА:

Nfnixbot — это полностью закрытая, масштабируемая архитектура VPN, разработанная на Python. Главный приоритет — обеспечение высокой скорости соединения и 100% незаметность VPN-трафика для систем фильтрации и DPI (ТСПУ в РФ). Сервис не предназначен для коммерческой продажи, является частным решением.

ПРОТОКОЛЫ
VLESS (Reality), Trojan, ShadowSocks 2022
БЭКЕНД СТЕК
Python 3.11, PostgreSQL, Redis, Docker
